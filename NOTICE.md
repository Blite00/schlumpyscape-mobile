# Credits and licences

This repository is a combination of other people's work. Everything here is distributed under the GNU GPL v3 (see LICENSE), matching the
launcher it builds on.

* `launcher/` - the 2009Scape mobile launcher, https://github.com/2009scape/2009Scape-mobile, itself built on PojavLauncher
  (https://github.com/PojavLauncherTeam/PojavLauncher, LGPL-3.0 / GPL-3.0 parts). Changes here: touch/tap handling, long press,
  loading bar, in-game scaling, keyboard handling, config persistence.
* `client-mobile/` - a fork of Pazaz's RT4 client, https://github.com/pazaz/rt4-client (see its README), with OpenRS2 annotations
  left in. Changes here: mobile layout (bottom tab row, zoomed panel), touch camera/scroll/pinch, menu rows and map controls, GL fixes.
* The 2009Scape server (https://gitlab.com/2009scape/2009scape) is a separate project and is not included.
